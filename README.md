# 🎤 Сцена Пітч-дня

Статичний інструмент для онлайн-уроку в Google Meet (LetMe/teens, 9–10 років).
Діти виступають 30–60 секунд із кумедними винаходами, вчаться спокійно повертати собі слово,
коли перебивають, і не губитися, коли сміються. Спікер «виходить на сцену» як аватар, якого сам обрав.

- `stage.html` — **сцена**, її демонструють у Meet (вкладка Chrome + «Поділитися аудіо вкладки»).
- `pult.html` — **пульт** учительки, окрема вкладка, її **не** демонструють.
- `index.html` — стартова сторінка з посиланнями та інструкцією.

Vanilla HTML/CSS/JS, без збірки. Синхронізація — `BroadcastChannel('pitchday-stage')`
з резервом через події `localStorage`. Стан зберігається в `localStorage`, тож перезавантаження вкладок нічого не ламає.

## Публікація на GitHub Pages

1. Settings → Pages → *Build and deployment*: **Deploy from a branch**, гілка `main`, папка `/ (root)`.
2. Через хвилину сайт буде за адресою `https://<користувач>.github.io/<репозиторій>/`.

Усі посилання відносні, тож репозиторій можна перейменувати (наприклад, на `pitchday-stage`) — нічого не зламається.

## Звуки

Дивіться [`sounds/README.md`](sounds/README.md): потрібен лише один файл — оплески.
Якщо файлів немає — грають запасні сигнали Web Audio, помилок не буде.

# 📋 Інструкція для вчительки

## Перед уроком (5 хвилин)

1. Відкрийте сайт у **Google Chrome**.
2. Натисніть **«Пульт»** — відкриється вкладка пульта.
3. Натисніть **«Сцена»**. Перетягніть вкладку сцени вбік, щоб вона стала **окремим вікном**.
4. На сцені натисніть велику кнопку **«▶ Відкрити сцену»** — так браузер дозволить звук.
5. На пульті вгорі має бути **🟢 Сцена на зв'язку · звук увімкнено**. Натисніть **🔔 Перевірити звук**.

> Пульт і сцена мають бути відкриті в **одному браузері на одному комп'ютері**.

## Як показати сцену в Meet зі звуком

1. У Meet — **«Показати екран»**.
2. Оберіть **«Вкладка Chrome»** (не «Весь екран» і не «Вікно» — інакше не буде звуку).
3. Виберіть вкладку **«Сцена Пітч-дня»**.
4. Увімкніть перемикач **«Поділитися також аудіо вкладки»**.
5. **«Поділитися»**. Повертайтеся до Meet і пульта — сцена працює сама.

> Пульт **не демонструйте**: на ньому імена, чекліст і нотатки.

## Пульт: дві вкладки

**🛠️ Підготовка** — список дітей, конструктор аватара (розгортається для дитини, згортається після «✅ Готово»),
поле «Винахід», печатки з тренувань, режими екрана (Галерея / Сцена / Фінал), «Показувати ім'я», «Шпаргалка»,
звук, підсумок і «🧹 Новий урок». Видалення дитини — через «⋯» з підтвердженням на сторінці.

**🎤 Пітч** — один екран без прокрутки (ноутбук 1366×768): дитина на сцені, таймер 30/45/60 с,
«🙋 Питання журі» + список питань, «👏 Оплески», «🌟 Незбивний момент», печатка «Винахідник»,
чекліст із 6 пунктів, нотатка і велика кнопка «Наступний ▶».

## Під час уроку

1. **Тренування викликів** проходять на слайдах — сцена для них не потрібна.
2. **Підготовка:** додайте дітей; у режимі **🖼️ Галерея аватарів** дитина каже «Персонаж 3, зелений, сова», ви збираєте аватар. Вставте винахід.
3. **Пітч:** «▶ Почати з першої дитини» → оберіть 30/45/60 с → **▶️ Старт**. Останні 10 с — жовте кільце, далі тихий «дзинь» і «Час фінішувати 🏁». Виступ не обривається.
4. Під час виступу: **🙋 Питання журі**, **👏 Оплески**, **🌟 Незбивний момент**, **💡 Печатка «Винахідник»**.
5. Чекліст і нотатка; тривалість підставляється з таймера сама.
6. **Наступний ▶** — наступна дитина. Після останньої — **🎉 До фіналу**.
7. Після уроку: скопіюйте підсумок (текст / CSV), потім **🧹 Новий урок**.

Ефекти (хмарки журі, оплески, «незбивний момент») показуються лише в режимі «Сцена».

## Якщо щось пішло не так

- **Діти не чують звуку** — перезапустіть демонстрацію з «Поділитися також аудіо вкладки»; перевірте, що на пульті не ввімкнена «Тиша».
- **На пульті 🟡** — перейдіть на сцену й натисніть «▶ Відкрити сцену».
- **На пульті 🔴** — сцену закрито, відкрийте її знову.
- **Сцена дрібна / з чорними смугами** — розгорніть вікно сцени або натисніть F11.
- **Новий урок** — «🧹 Новий урок» у вкладці «Підготовка» (спершу скопіюйте підсумок).
