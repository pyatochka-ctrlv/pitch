# Звуки для «Сцени Пітч-дня»

Потрібен лише **один файл** — покладіть його в цю папку з точно такою назвою.
Підходять формати `.mp3` (найкраще), `.ogg` або `.wav`.

| Файл           | Що це    | Коли звучить                                   | Довжина |
|----------------|----------|------------------------------------------------|---------|
| `applause.mp3` | Оплески  | Кнопка 👏 «Оплески», початок фіналу 🎉          | 2–4 с   |

## Де взяти CC0-звуки (вільні, без зазначення авторства)

- https://freesound.org — у фільтрі «License» оберіть **Creative Commons 0**
- https://pixabay.com/sound-effects/
- https://opengameart.org — фільтр «CC0»

Перевіряйте на сцені кнопкою **🔔 Перевірити звук** у вкладці «Підготовка» і самою кнопкою «👏 Оплески».

## Що буде, якщо файлу немає

Нічого страшного: сцена зіграє запасні оплески, згенеровані в браузері (Web Audio). Помилок не буде.

Решта сигналів (дзинь таймера, печатка, питання журі, поява аватара, «незбивний момент», фанфари фіналу)
генеруються в браузері — файли для них не потрібні.
