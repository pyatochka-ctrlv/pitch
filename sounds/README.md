# Звуки для «Сцени Пітч-дня»

Покладіть у цю папку чотири файли з **точно такими назвами**.
Підходять формати `.mp3` (найкраще), `.ogg` або `.wav`.

| Файл              | Що це                      | Коли звучить                         | Рекомендована довжина |
|-------------------|----------------------------|--------------------------------------|-----------------------|
| `giggle.mp3`      | Короткий смішок 1–2 людей  | Виклик 😄 «Смішок»                    | 1–2 с                 |
| `laugh-wave.mp3`  | Хвиля сміху залу/класу     | Виклик 😂 «Хвиля сміху»               | 2–4 с                 |
| `applause.mp3`    | Оплески                    | Реакція 👏 «Оплески + конфеті», фінал | 2–4 с                 |
| `phone-ring.mp3`  | Дзвінок телефону           | Виклик 📞 «Телефонний дзвінок»        | 2–4 с (далі обрізається на 3,5 с) |

## Де взяти CC0-звуки (вільні, без зазначення авторства)

- https://freesound.org — у фільтрі «License» оберіть **Creative Commons 0**
- https://pixabay.com/sound-effects/
- https://opengameart.org — фільтр «CC0»

Порада: обирайте добрий, «теплий» сміх (без глузування), і невеликої гучності.
Завжди перевіряйте на сцені кнопкою **🔔 Перевірити звук** та самими викликами.

## Що буде, якщо файлу немає

Нічого страшного: сцена сама зіграє простий запасний сигнал (Web Audio)
і покаже візуальний ефект. Помилок не буде.

Решта сигналів (дзинь таймера, печатка, питання журі, поява аватара тощо)
генеруються в браузері — файли для них не потрібні.
